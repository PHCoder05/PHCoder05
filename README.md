## What I care about

- **End‑to‑end ownership** — from schema and auth to the last meter of the UI  
- **Operational truth** — logs, health, backups, cutovers; not demos that only work on localhost  
- **Clean contracts** — mobile ↔ API ↔ vendors stay boring and predictable  
- **Speed with judgment** — ship fast, keep the blast radius small  

I live where product pressure meets infrastructure reality: payments, identity, webhooks,  
containers, and the awkward middle mile between a café counter and a cloud edge.
